# Emerging Technology Diffusion Agent

Assignment 5 specialist built on the frozen MASY1800 scaffold v1.0. It assesses diffusion of generative-AI ambient clinical documentation using Rogers' adopter categories and five perceived innovation attributes. See `specialist_instructions.md`, `cases/`, `responses/`, and `records/`.

The agent provides decision support about diffusion and timing. It does not decide whether an organization should adopt or approve clinical use.
